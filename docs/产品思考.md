# 回声 · 以人为中心的创作平台

## 核心判断

书影音是入口，人的经历与表达是核心。作品不是消费数量的奖牌；一个人为什么在某个时刻被触动，比他收藏了多少东西更重要。

回声的循环是：带来过去的输入 → 重访真实经历 → 发现问题与连接 → 整理有出处的材料 → 写出自己的理解 → 自主选择分享 → 在另一个人的作品中遇见新问题。

“现代文艺复兴”在这里先落实为可使用的创作基础：普通人有地方保存经历、形成判断、完成表达、保留署名与来路，并决定何时与谁分享。它不是对平台已经形成大规模社群的宣传。

## 三个空间

### 私人书房

收藏、日期、个人评分、短评、回忆、手记与未公开草稿按账号隔离。用户可以从豆瓣备份、NeoDB 正式只读授权或 CSV 带入历史。导入预览让用户先看清将保存什么；无关的私信、联系人等数据不进入平台。

### 创作室

输入回顾提供时间线与主题统计，主题建议附实际作品与用户感受作为线索。创作项目支持随笔、视频脚本与播客提纲；材料架保留自己的短评与补充回忆，出处可插入正文。用户写出自己的内容，预览并导出 Markdown / HTML。

没有替用户虚构过去，也没有把作品简介冒充用户自己的观点。结构与提示只是辅助，当前没有接入大模型代写。

### 人与作品

每一件公开作品都由作者明确选择分享，包含公开署名、自愿介绍、创作问题、正文和选定引用作品。私人短评、回忆、其他收藏和草稿不会自动公开。公开版是快照，之后修改私人草稿不会直接改变它。

读者先看见一个人的关切，再读他的作品。作者页连接其主动公开的作品。读者可以由此建立私人回应草稿，并保留对原作者的引用；这不会自动发布，也不会发送通知。作者可撤回公开版本，私人稿件保留。平台初始没有虚构用户或伪造的公开作品。

## 审美与交互

沿用暖纸色、墨绿色与宋体的私人图书室气质，真实书封、电影海报和专辑封面带来作品辨识度。18张精选封面在本地保存，附来源；陌生作品可查找候选，由用户核对后选择。

人的头像先用公开署名首字，不生成虚构人像。公开列表按发表时间排列，突出创作问题、原文与来路；目前不做点赞量排名、阅读量竞争或自动通知。

## 关联的可信程度

事实关系（同一创作者）、编辑主题与情绪、个人联想分别理解。加权标签关联提供可解释的探索路径，不代表作品质量、心理诊断或因果判断。未知创作者与“未分类”不会形成假连接；缺失情绪不会默认给所有导入作品贴上“沉静”。

主题总结只看已体验与体验中的记录，不把愿望清单当作过去经历。公开引用只展示用户明确选择公开的作品元数据，不携带私人的阅读笔记。

## 已实现与实际边界

多用户登录、云端隔离和版本冲突处理；豆伴九张收藏表 XLSX、本地 CSV 与 NeoDB 只读 OAuth 接入；真实封面和候选查询；历史回顾、回忆、主题线索；创作、保存、预览与导出；自选公开、作者页、私人回应草稿、撤回公开版。

豆瓣官方 OAuth 没有可核实的新应用申请通道，尚未接入。NeoDB 限 neodb.social，读取完成请求撤销临时 token；真实账号的最终授权必须由用户本人确认。当前不包含多人同时编辑、评论私信、商业支付、语义向量或大模型代写，不能据此宣称已经是成熟的大规模社交平台。

## 下一步应由真实使用决定

观察用户是否能从自己的五部作品与一段经历开始，写出一件愿意保留的表达；再观察读者能否从一个人的关切出发，写出新的回应。只有这条循环成立，才考虑协作编辑、创作者小组和更丰富的研究工具。
