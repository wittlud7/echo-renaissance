# 账号与历史导入证据 · 2026-10-22

## 豆瓣：实际备份兼容，不冒充正式授权

本轮访问旧开发者站与旧 OAuth 文档，未取得可验证的新应用申请路径，因此不宣称豆瓣账号 OAuth 可用。

豆伴官方导出源码：https://github.com/doufen-org/tofu/blob/56a9801922f67ee82b72e62ee4606d0b78f4a8fc/extension/explorer.js#L1510

支持九个工作表：读过/在读/想读、看过/在看/想看、听过/在听/想听。字段为：标题、简介、豆瓣评分、链接、创建时间、我的评分、标签、评论、可见性。工作表决定类型和状态；我的评分为五星，不读取大众评分作为个人分。源码交叉验证：https://github.com/neodb-social/neodb/blob/main/neodb/journal/importers/douban.py 。

仅处理上述收藏表。豆邮、联系人、日记、长评等表会跳过并显示数量。XLSX 在浏览器中有界解压和解析，不运行公式、不读取外部关系；文件大小12MB，相关解压内容40MB，单个XML15MB，最多10000行。

## NeoDB：正式只读 OAuth

现行文档：https://neodb.net/api/ ，https://neodb.social/api/openapi.json 。

注册 `POST /api/v1/apps`，scopes 为 read；授权 `/oauth/authorize`，交换 `/oauth/token`；本人 `/api/me`；收藏 `/api/me/shelf/{complete,progress,wishlist}`，page_size=50；撤销 `/oauth/revoke`。应用注册源码：https://github.com/neodb-social/neodb/blob/main/takahe/api/views/apps.py ，授权与撤销：https://github.com/neodb-social/neodb/blob/main/takahe/api/views/oauth.py 。

服务器动态注册本站回调，客户端只拿授权链接。回调校验当前用户、来源、state 哈希和有效期；token 只保存在服务端，必须精确为 read scope。导入只读书、电影/电视、音乐，不读取游戏等类别。逐页读取完成请求撤销授权；撤销失败保留连接供用户继续撤销，不伪报成功。中途离开时可在本站或 NeoDB 应用设置撤销。

Mark 的 comment_text、tags、rating_grade 是用户记录，item.description 不是用户自己的观点；导入不会混淆两者。credits 只取作者、导演、艺术家等明确角色。rating_grade 为十分制。源码：https://github.com/neodb-social/neodb/blob/main/neodb/journal/apis/shelf.py 。

NeoDB CSV 官方导出格式来源：https://github.com/neodb-social/neodb/blob/main/neodb/journal/exporters/csv.py 。原生 NDJSON 是多种独立记录，不等同 API JSON，因此本轮没有伪称支持。

## 多用户与开放访问

入口可公开浏览，私人记录按 Sites 提供的稳定账号 ID 保存。匿名请求不能读写 vault；OAuth state 和 token 也绑定同一账号。站点开放不会把任何人的收藏、回忆、草稿变为公开内容。

数据库单行限制参考：https://developers.cloudflare.com/d1/platform/limits/ 。较大 vault 分块保存，所有新块和头版本比较在同一事务中完成；读取头与数据块也在同一事务中完成。
