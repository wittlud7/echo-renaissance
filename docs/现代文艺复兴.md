# 回声：把人的经验重新放回创造中心

平台的核心问题是：一个人积累了大量观看、阅读、聆听和生活经历，如何从这些输入中发现自己真正想表达的问题？

## 已落实的路径

1. **注意**：工作台允许从一句尚不完整的想法开始。私人札记支持随笔、观察和经历，自由标签与经历日期均可留空。
2. **留存**：本机草稿与登录后的个人云端空间保存记录；作品、札记和回忆保留独立来源。
3. **连接**：分词与主题标签匹配过去的文字，显示具体共同线索。用户选择保留或移除连接，不输出人格标签，也不以相同日期假装存在因果关系。
4. **命名**：创作罗盘要求作者填写问题、缘由、读者和形式。系统把选择的材料放进私人侧栏，正文留给作者。
5. **回应**：作者决定是否公开。公开版保留愿意分享的正文、署名、问题和书影音/历史出处；读者可从作品建立私人回应草稿。

## 文艺复兴如何进入产品

采用历史中的实际工作作为当代练习的起点：达·芬奇的跨领域札记、丢勒对身体与普通物品的观察、版画使作品与读者相遇的方式。每项均链接到博物馆官方事实来源；练习明确标为平台的当代设计。

视觉采用刊物的节奏、札记的留白、手稿与排印的拼贴。真实历史图像有署名与许可，用户文字与历史作品分开呈现。保留作品独立风格，让表达形式可以随创作主题变化。

“新的文艺复兴”是今天的邀请，不是对复杂历史的单一概括。平台关注的是普通人是否能重新信任自己的观察、珍惜尚未成熟的想法，并形成属于自己的判断。

## 当前边界

「兴趣测绘」让用户选择偏爱的主题、情绪和媒介，也可标记暂时少看的主题；推荐卡片的“想了解 / 少推荐这类”、已体验作品评分会持续校准个人偏好。排序使用可解释的内容特征向量：标签反馈和评分塑造主题偏好，媒介与情绪偏好共同参与，再由天气和当前心情微调。每条结果列出匹配理由，已体验、计划体验或明确略过的作品不会重复出现。

「我的宇宙」把全库或个人收藏展示成作品网络，关系来自共享主题、情绪和已知创作者；用户可选择任意节点查看相邻作品及具体理由。星图最多绘制72件作品，以保证浏览器交互流畅。

算法参考开源 [LensKit](https://github.com/lenskit/lkpy) 推荐工具的内容偏好与相似项目思路，本站独立实现，没有复制其源码或引入运行依赖。目前仅依据当前用户主动记录，不做跨用户画像或协同过滤；多用户反馈样本尚未形成，也不据此冒充全网流行度。记录稀少时结果会留出探索空间，标签可以帮助发现更具体的关联。历史素材目前为三组经核实案例，不冒充完整历史数据库。

这是可通过手机浏览器访问的网站；尚未封装成微信小程序。实时协作、社交消息和未经用户确认的自动公开均未加入。
