## 浏览器完整流程

- 本地 Sites 登录后创建独立空间；匿名 vault 请求返回401，退出后不显示刚才账号的私人项目。
- 导入实际结构的合成豆伴 XLSX：读过表被识别，个人五星与日期保留；豆邮表被跳过，私信内容未入库。
- 再次导入同一文件预览显示0条新增、1条已存在，无法重复确认。
- 导入一部书和一部电影，发现共同主题，建立随笔、写正文、标记完成、导出 Markdown，刷新后恢复114字测试正文。
- 补充一段回忆并同步。
- 模拟另一设备写入后，本机写入返回409；明确合并后远端新增手记与本机正文都保留。
- NeoDB 前端受控分页读取三类书架、预览确认和十分制转换通过；授权链接以顶层导航交给用户确认。真实 NeoDB 账号的最终授权、站点外 consent 页面及生产 token 交换尚未用真人账号验证。
- 本地公开测试作品后，用独立的匿名浏览器上下文读取正文；匿名 vault 仍401。公开响应只含正文、公开署名与介绍、创作问题、选择的作品元数据，不含私密记录。
- 匿名读者从公开作品建立私人回应草稿：正文为空，不自动发布或通知，保留作者引用。
- 作者撤回后公开接口404，私人项目数量和正文保留。测试作品未发送到生产站点。
- 390px 七个主要界面无横向溢出；真实封面18/18已解码与人工查看。书封搜索接口实际返回候选。

## 验证边界

本地预览身份是框架的模拟登录；它不是两个真实生产账号。生产发布、公开访问、D1迁移与匿名权限以最终部署状态和上线探测记录为准。第三方服务临时不可用时，导入文件仍可用；未把模拟 OAuth 数据说成真人已授权。
